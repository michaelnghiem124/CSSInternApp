Hard rules (capacity, schedule conflicts, real committees and coaches) are enforced in code and the model must fix any violation.

    Opportunities

    Connectors read the official public job feeds (Workday, Oracle Cloud, iCIMS, Greenhouse; USAJOBS with a free key) of Think Tank organizations, plus Minnesota Fortune 500 employers with no Summit connection (marked as such), plus other Minnesota early-career tech roles from the Adzuna API (2 calls per refresh, at most once every 20 hours, to save the free allowance). A Job Classifier agent labels each new posting: internship, co-op, or entry-level; field; relevance; location; eligibility. Interns only see early-career, relevant, US roles you haven't hidden.
